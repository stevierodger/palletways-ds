# Image

Aspect-ratio image frame (landscape, square, portrait).

**Figma:** `image` (`2283:9012`)

## Props

| Prop | Values | Default |
|------|--------|---------|
| `src` | string | required |
| `alt` | string | `""` |
| `aspect` | `landscape` \| `square` \| `portrait` | `landscape` |

## Assets

Sample landscape JPEG: `assets/landscape.jpg`
