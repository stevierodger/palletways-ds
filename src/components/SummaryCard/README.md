# SummaryCard

Order summary card: header, consignment (collection/delivery), price breakdown, optional footer actions.

**Figma:** `summary-card` (`2283:10482`)

## Composes

- `SummaryHeader` / `SummaryAction`
- `SummaryFooterPrice`
- `SummaryFooterActionPanel` (when `showActionPanel`)

## CSS variables

`--surface-color-bg-subtle-default`, `--border-color-border-*`, `--color-status-info-strong-default`, `--color-status-success-strong-default`, `--typography-body-*`, `--spacing-comp-*`.
