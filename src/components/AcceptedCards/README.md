# AcceptedCards

Row of accepted payment card brand logos (Visa, Mastercard, Amex, Discover).

**Figma:** `info.pallet-selection/Accepted cards` (`2135:10505`)

Each SVG already contains its own white card and border from Figma, so the row adds no extra chrome — logos render at their Figma sizes (Visa 36×21, Mastercard 21×13, Amex 42×21, Discover 33×21) with an 8px gap. Total row: 156×21.
