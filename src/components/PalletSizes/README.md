# PalletSizes

Isometric pallet illustration with person scale silhouette. Figma `pallet-sizes` (`2012:2844`).

## States

`mini` | `x-small` | `small` | `medium` | `narrow-medium` | `large` | `x-large`

## Assets

- `assets/person.svg` — grey scale silhouette
- `assets/*.png` — cargo/pallet PNG per size variant

## CSS variables

- `--button-color-bg-subtle-default` — tile background (#f1f7ff)
- `--spacing-comp-x-md`, `--spacing-comp-x-lg` — padding (16×24)
