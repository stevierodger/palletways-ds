# SummaryFooterPrice

Order summary price breakdown: sub total, VAT, and total. Figma `summary-footer/price` (`2287:10609`).

## CSS variables

- `--text-color-text-body-secondary-default` — row colour (#44536a)
- `--typography-body-font-size` / `--typography-body-line-height` — Body Neutral / Median
- `--font-weight-neutral` — 400 for subtotal/VAT rows
- `--font-weight-median` / `--font-weight-semibold` — 600 for Total row
