# Chip

Status chip from Figma `Chip` (`1:98`). Tones map from `Property 1`: RED/YELLOW/GREEN/BLUE/PURPLE. Leading slot uses the Figma `Icons` set (`dot` default; also `alert` / `check` / `cross`).

## Files

| Path | Role |
|------|------|
| `Chip.tsx` / `Chip.css` | Component |
| `chip.figma.ts` | Code Connect |
| `index.ts` | Exports |

## Notes

Figma colours are hardcoded hex (no WEB semantic tokens on this set). Glyphs use `currentColor` so they match tone text.
