# FieldTitle

Form field title line in active (bold) or secondary (placeholder-weight) tone.

**Figma:** `field-title` (`2125:12386`)

## Props

| Prop | Values | Default |
|------|--------|---------|
| `tone` | `active` \| `secondary` | `active` |
| `title` | string | `Full name*` |
