# SummaryHeader

Section header for order summary blocks. Figma `summary-header` (`2283:10525`).

Composes `SummaryAction` (default `edit` variant) on the trailing edge.

## CSS variables

- `--text-color-text-body-secondary-default` — title colour (#44536a)
- `--typography-body-font-size` / `--typography-body-line-height` — Body Median
- `--font-weight-semibold` — 600
